# Bench fixtures

- `header.html`: the header example of the wkhtmltopdf 0.12.6 manual
  (`wkhtmltopdf --extended-help`, section "Headers And Footers", text in
  `src/pdf/pdfdocparts.cc`), unchanged. Its `subst()` script reads the page
  number, total and section from the URL parameters wkhtmltopdf adds.
  License: LGPL-3.0-or-later, Copyright 2010-2020 wkhtmltopdf authors.
- The long document of `bench/header.ts` and the headings document of
  `bench/outline.ts` are generated by those scripts.
